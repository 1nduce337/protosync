# ProtoSync 0.0.1

第一个公开版本：macOS 与 Android。局域网点对点、端到端加密的剪贴板与文件同步，不经过任何服务器。
First public build for macOS and Android: local-first, end-to-end encrypted clipboard and file sync over your LAN.

## 下载

| 文件 | 平台 |
|---|---|
| `ProtoSync-0.0.1-macOS.zip` | macOS 13 及以上（Apple 芯片与 Intel） |
| `ProtoSync-0.0.1-android.apk` | Android 9 及以上 |
| `ProtoSync-0.0.1-SHA256.txt` | 两个文件的 SHA-256 校验值 |

iOS 版需要开发者签名才能安装到 iPhone，暂不随本版本发布；可按 README 从源码构建。

## 主要功能

- **自动发现**：同一局域网内的设备自动出现，无需填写地址。
- **6 位配对码**：在一台设备上点“配对”，两台设备显示同一个配对码，核对一致后在另一台设备上接受即可。
- **剪贴板同步**：Mac 上复制即同步；Android 点“发送剪贴板”发送，收到的内容自动进入剪贴板。支持文本和图片。
- **文件收发**：Mac 上把文件拖到设备头像即可发送；Android 点设备头像选择文件。每个文件都做 SHA-256 校验。
- **按设备设置“自动接收文件”**：默认开启；关闭后，这台设备发来的每个文件都需要你确认。
- **双向移除**：在任意一台设备上移除配对，另一台也会自动移除（对方不在线时，等它下次上线时移除）。
- **剪贴板历史**：最近 6 条，点按即可再次复制；只存在内存里，不写入磁盘。
- **菜单栏提示**：Mac 菜单栏图标在复制发出时显示上箭头，收到其他设备的剪贴板或文件时显示 Lime 下箭头；可选系统通知。
- **跳过密码**：Mac 上从密码管理器（1Password、钥匙串等）复制的内容不会被同步。
- **端到端加密**：每条连接都有独立的会话密钥（前向安全），所有内容都经 ChaCha20-Poly1305 加密。

## 安装

### macOS

1. 解压 `ProtoSync-0.0.1-macOS.zip`，把 `ProtoSync.app` 拖进“应用程序”。
2. 本版本未经 Apple 公证，首次打开会被拦截：
   - 打开“系统设置 › 隐私与安全性”，在底部找到 ProtoSync，点“仍要打开”；
   - 或在终端运行 `xattr -dr com.apple.quarantine /Applications/ProtoSync.app`。
3. 系统询问“本地网络”权限时选择允许，否则无法发现其他设备。
4. ProtoSync 只出现在菜单栏（没有 Dock 图标）：左键打开面板，右键打开菜单。

### Android

1. 在手机上下载 `ProtoSync-0.0.1-android.apk` 并打开。
2. 按提示允许“安装未知应用”，然后安装。
3. 首次启动时允许通知权限；ProtoSync 以前台服务常驻，用来接收剪贴板和文件。

## 注意事项

- **所有设备需要同时升级到 0.0.1。** 本版本使用 v2 协议，旧版本无法与它连接（会提示“协议版本不兼容”）。
- **之前用旧版本配对过的设备**，建议在两端都移除后重新配对，以使用新的配对码流程。
- 设备需要在同一个局域网内。访客网络、部分热点会阻止设备互相发现，这时可在 Android 设置页用“手动连接”输入对方的 IP:端口。
- macOS 版使用临时签名（ad-hoc），未经公证；Android 版使用自签名证书。以后的版本会沿用同一证书，可以直接覆盖安装。
